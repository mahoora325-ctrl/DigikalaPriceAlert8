# هشدار قیمت دیجی‌کالا

اپلیکیشن اندروید که قیمت یک یا چند محصول دیجی‌کالا را در پس‌زمینه پایش می‌کند
و وقتی قیمت به زیر سقفی که شما تعیین می‌کنید برسد، نوتیفیکیشن می‌فرستد.

## نصب برای اولین بار
پروژه شامل یک workflow آماده در `.github/workflows/build.yml` است که با هر
push روی GitHub، به‌طور خودکار **دو** فایل نصبی (APK) می‌سازد:

1. یک ریپازیتوری در GitHub بسازید و محتوای این پوشه را در آن آپلود کنید
   (پوشه‌ی مخفی `.github` را هم حتماً آپلود کنید).
2. به تب **Actions** بروید و صبر کنید ساخت با علامت ✔️ سبز تمام شود.
3. روی همان اجرای موفق کلیک کنید، از بخش **Artifacts** یکی از این دو را
   دانلود کنید:
   - **digikala-price-alert-debug** → برای نصب مستقیم روی گوشی خودتان و تست
     (شامل `app-debug.apk`)
   - **digikala-price-alert-release** → برای انتشار در استورهایی مثل مایکت یا
     کافه‌بازار (شامل `app-release.apk`)؛ این نسخه با یک کلید امضای release
     واقعی امضا شده، نه کلید دیباگ، پس استورها آن را قبول می‌کنند.
4. فایل APK را به گوشی منتقل و نصب کنید (نیاز به فعال کردن موقت «نصب از
   منابع ناشناس» دارید چون از گوگل‌پلی نیست).

## به‌روزرسانی به نسخه‌ی جدید
هر وقت فایل‌های پروژه تغییر کردند و نسخه‌ی جدیدی ساختید، کافی است APK جدید را
مثل بار اول نصب کنید — **نیازی به حذف نسخه‌ی قبلی نیست**. نسخه‌ی debug همیشه با
`app/debug.keystore` و نسخه‌ی release همیشه با `app/release.keystore` امضا
می‌شود؛ چون هرکدام ثابت هستند، گوشی (یا استور) هر بار آن‌ها را «آپدیتِ» همان
برنامه می‌شناسد، نه یک برنامه‌ی جدید — به شرط اینکه هر بار همان نوع (debug یا
release) را که قبلاً نصب کرده بودید دوباره نصب کنید.

⚠️ چون نسخه‌ی debug و نسخه‌ی release با دو کلید متفاوت امضا می‌شوند، اگر قبلاً
نسخه‌ی debug را روی گوشی خودتان نصب کرده بودید و حالا برای اولین بار می‌خواهید
نسخه‌ی release را (مثلاً برای تست قبل از ارسال به مایکت) روی همان گوشی نصب
کنید، باید یک‌بار نسخه‌ی قبلی را Uninstall کنید؛ از آن به بعد، به‌روزرسانی‌های
بعدیِ همان نوع بدون نیاز به حذف نصب می‌شوند.

## آموزش استفاده از برنامه

### افزودن محصول برای پایش
1. لینک محصول را از دیجی‌کالا کپی کنید (یا فقط کد عددی محصول را وارد کنید).
2. سقف قیمت مورد نظر را به تومان وارد کنید.
3. «افزودن به پایش قیمت» را بزنید.

برنامه هر ۱۵ دقیقه به‌صورت خودکار قیمت را بررسی می‌کند؛ دکمه‌ی «بررسی فوری همه
موارد» هم یک بررسی آنی انجام می‌دهد. برای حذف یک محصول از لیست، دکمه‌ی «حذف»
کنار همان محصول را بزنید؛ برای تغییر سقف قیمتش هم دکمه‌ی «ویرایش سقف» کنارش
هست. دکمه‌ی «دیجی‌کالا» هم صفحه‌ی همان محصول را در اپلیکیشن دیجی‌کالا (در صورت
نصب بودن) یا مرورگر گوشی باز می‌کند.

وقتی قیمت به زیر سقف برسد نوتیفیکیشن دریافت می‌کنید. اگر بعداً قیمت دوباره بالای
سقف برود و سپس دوباره پایین بیاید، هشدار مجدد ارسال می‌شود.

با زدن روی هر باکس محصول در لیست، تاریخچه‌ی کامل تغییرات قیمتش (از چه مبلغی به
چه مبلغی، و در چه تاریخی) نمایش داده می‌شود. تمام تاریخ‌ها و ساعت‌ها به‌صورت
شمسی نمایش داده می‌شوند. عکس هر محصول هم (در صورت موجود بودن) سمت چپ باکسش
نمایش داده می‌شود.

درست زیر دکمه‌های «جستجوی محصول» و «بررسی فوری»، یک منوی کشویی «چیدمان لیست»
هست؛ با لمسش گزینه‌ها باز می‌شوند و با انتخاب هرکدام، فهرست فوراً بر همان اساس
مرتب می‌شود: ترتیب افزودن (پیش‌فرض)، قیمت فعلی (کم به زیاد یا زیاد به کم)، یا
تاریخ آخرین تغییر قیمت (جدیدترین یا قدیمی‌ترین اول).

اولین باری که برنامه را باز می‌کنید، برای اینکه اندروید پایش دوره‌ای را در
پس‌زمینه نبندد، خودش یک‌بار از شما می‌خواهد بهینه‌سازی باتری را برای این اپ
غیرفعال کنید؛ پیشنهاد می‌شود آن را تأیید کنید.

### منوی تنظیمات و درباره برنامه
از سه‌نقطه‌ی بالای صفحه چند گزینه در دسترس است:

- **تنظیمات**: انتخاب رنگ قالب برنامه از بین چند رنگ آماده (بلافاصله روی نوار
  بالا و دکمه‌ها اعمال می‌شود)، انتخاب صدای هشدار از بین صداهای گوشی یا فایل‌های
  صوتی دلخواه (فایل انتخابی داخل حافظه‌ی خود برنامه کپی می‌شود تا بعداً هم
  همیشه قابل پخش بماند)، و یک دکمه‌ی «ارسال هشدار آزمایشی» برای تست فوری اینکه
  نوتیفیکیشن و صدایش درست کار می‌کنند.
- **درباره برنامه**: نام برنامه، شماره نسخه، و نام توسعه‌دهنده.

تمام اعداد نمایش‌داده‌شده در برنامه (قیمت‌ها، تاریخ‌ها، شماره نسخه) به‌صورت
ارقام فارسی هستند. فونت کل برنامه هم «طنین» است.

## نکات مهم
- این اپ از یک **API غیررسمی و مستندنشده‌ی دیجی‌کالا** استفاده می‌کند
  (`https://api.digikala.com/v2/product/{id}/`). دیجی‌کالا هیچ تعهدی به پایداری
  این API ندارد و ممکن است ساختار پاسخ یا دسترسی به آن در آینده تغییر کند.
- برنامه اولین بار که اجرا می‌شود خودش درخواست غیرفعال‌سازی بهینه‌سازی باتری را
  نمایش می‌دهد؛ اگر رد شد یا بعداً خواستید تغییرش دهید، از تنظیمات گوشی هم
  می‌توانید این کار را برای این اپ انجام دهید.
- در اندروید ۱۳ به بالا، اولین بار که اپ را باز می‌کنید مجوز نمایش نوتیفیکیشن
  درخواست می‌شود؛ حتماً آن را تأیید کنید.
- داده‌ها فقط به‌صورت محلی روی گوشی ذخیره می‌شوند؛ هیچ سروری در کار نیست.
- هشدار «نصب از منبع ناشناس» موقع نصب APK، یک هشدار امنیتی استاندارد خودِ
  اندروید برای هر برنامه‌ای است که از گوگل‌پلی نصب نمی‌شود، نه خطای این برنامه؛
  کافی است یک‌بار اجازه‌ی نصب را برای همان اپلیکیشنی که با آن APK را باز
  می‌کنید (مثلاً مدیر فایل یا مرورگر) از تنظیمات گوشی فعال کنید.
